# **App Name**: MERBOOK

## Core Features:

- Google User Authentication: Securely log in to the system using existing Google accounts.
- Meeting Room Availability Viewer: View all meeting rooms and their availability status for selected dates, presented clearly for quick booking decisions.
- Booking Creation & Conflict Prevention: Easily book an available meeting room for a specific time slot, with built-in mechanisms to automatically prevent any time overlaps or double bookings.
- User Booking Management: Authenticated users can view a personalized list of their own reservations and have the ability to cancel them when no longer needed.
- Admin Room Configuration: Provide administrative users with a dedicated interface to add new meeting rooms, edit existing room details, delete rooms, and toggle their active status.

## Style Guidelines:

- The overall scheme will be light, conveying professionalism and clarity suitable for a corporate environment. The primary color is a composed medium blue (#226DD4), chosen for its reliable and trustworthy association. The background color is a heavily desaturated hint of blue (#ECF3FB) that provides a clean canvas. An accent color of bright cyan (#1ACAEA) is used for calls to action and to draw attention to key interactive elements, providing a lively contrast.
- The primary font for both headlines and body text is 'Inter', a modern grotesque sans-serif. Its objective and neutral aesthetic promotes readability and fits the application's focus on clarity and efficiency for an internal tool.
- Utilize a consistent set of clean, modern, and simple line icons. Icons should clearly represent actions like 'book', 'cancel', 'view calendar', 'room details', 'admin settings', and 'user profile' to maintain intuitive navigation and understanding.
- Implement a responsive, dashboard-style layout designed for clarity and quick access to core features. Key views like the room availability calendar should be prominent. Information should be presented in a structured and easy-to-digest manner, minimizing cognitive load for users across various screen sizes.
- Incorporate subtle, tasteful animations for transitions between different views or for indicating status changes (e.g., successful booking, cancellation). These animations should be fluid and quick, enhancing the user experience without causing delays or distractions.
